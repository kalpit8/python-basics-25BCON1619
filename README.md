# Python Basics – 25BCON1619

## Project Description

This repository contains basic Python programs created as part of the Python Basics coursework. The programs demonstrate fundamental Python concepts such as lists, dictionaries, loops, functions, recursion, and pattern printing.

## Programs Included

- `dictionary.py` – Dictionary operations
- `factorial.py` – Factorial of a number
- `fibonacci.py` – Fibonacci series
- `list.py` – List operations
- `multiplication.py` – Multiplication table
- `pattern.py` – Pattern printing program

## How to Run the Programs

1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run any program using:

```bash
python filename.py
```

Example:

```bash
python factorial.py
```

## Requirements / Dependencies

- Python 3.x
- No external libraries are required (uses only Python's built-in features).
